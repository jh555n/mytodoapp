# 실기기 인수 검사

이 체크리스트는 아직 수행하지 않았습니다. Android·iOS에서 각각 결과, OS 버전, 기기 모델을 기록합니다.

## 로컬 모드

- 네트워크를 끈 상태에서 할 일·카테고리·체크리스트를 저장한다.
- 앱 강제 종료 후 다시 열어 제목·날짜·색상·완료 기록을 확인한다.
- 캘린더에 연결하지 않은 데이터가 외부 서비스로 전송되지 않는지 확인한다.
- 자동 백업과 기기 전송에서 Todo DB와 인증 정보가 제외되는지 확인한다.
- 월·주 전환, 월 경계, 긴 제목, 큰 글씨, VoiceOver/TalkBack을 확인한다.

## 반복과 휴일

- 2026-01-31 시작 월 반복이 2/28, 3/31로 계산되는지 확인한다.
- 2026-10-09 시작, 다음 업무일 옵션은 10/12로 이동하는지 확인한다.
- 10/9·10/10·10/11의 일 반복이 10/12로 모여도 각각 완료 기록을 유지하는지 확인한다.
- 알 수 없는 연도의 공휴일 이동을 확정하지 않고 안내하는지 확인한다.
- 시간대와 DST를 변경하고 종일 날짜와 시간 지정 할 일을 구분해 확인한다.

## 알림과 빠른 등록

- 최초 허용·거부·설정에서 철회 후 동작을 확인한다.
- 앱 종료 및 Android 재부팅 후 예약을 확인한다.
- 잠금화면에서 내용이 노출되지 않고 위젯 탭 후 등록으로 연결되는지 확인한다.
- Android에서 잠금화면 위젯을 지원하지 않으면 홈 위젯을 확인한다.
- cold start와 이미 열린 앱에서 위젯 링크가 등록 화면을 한 번만 여는지 확인한다.

## 캘린더

- 연결 취소, 만료, 연결 후 접근 권한 철회, 다시 연결을 확인한다.
- 선택한 캘린더만 조회·등록 대상으로 사용되는지 확인한다.
- 외부 캘린더 이름·색상·Google 라벨을 바꾼 뒤 앱에 반영되는지 확인한다.
- 일반 외부 일정이 읽기 전용이고 완료·삭제되지 않는지 확인한다.
- 앱 소유 일정을 외부에서 변경·삭제한 뒤 앱에 반영되는지 확인한다.
- 같은 일정을 양쪽에서 수정해 선택 전 내용이 보존되는지 확인한다.
- 전송 중 네트워크를 끊고 재시도하여 Google 이벤트가 중복되지 않는지 확인한다.
- 연결 해제 시 유지·삭제 옵션과 외부 원본 보존을 확인한다.
- 같은 iCloud 캘린더를 EventKit과 CalDAV로 중복 연결하지 않도록 확인한다.
- CalDAV 사용자 지정 속성과 ETag, 시간대, 반복 인스턴스 응답을 실제 서버에서 확인한다.
